01 What is this assignment about?

In this assignment, you will practice your knowledge of joins, subqueries and functions to retrieve data from multiple tables in the football database.

02 Retrieving data

To complete this lab, answer the following questions using SQL queries.

For every SQL query, make sure you:

  • Name each column in the resulting view table.
  • Comment each query explicitly, saying what question you are answering.

03 Questions

Question 1: List each club name and the number of players currently under contract. Show only clubs that have more than 10 players, and sort the results from the highest to the lowest number of players.

Question 2: Display the player name, club name, and number of years remaining on their contract. Only include players whose contracts have not yet expired. Be ready to explain the results when you demonstrate your lab.

Question 3: Find the average wage for each nationality. Show only the nationalities whose average wage is higher than the overall average wage across all players.

Question 4: List the player names and club names for players who play in a club that has at least one player earning €50,000 or more per week.

Question 5: Return the names of clubs that currently have no players under contract.

Question 6: Write a query to achieve the following output:

  • The first column should display each player’s name
  • The second column should show their preferred foot
  • The third column should show values “Left-footed” if the player’s preferred foot is Left, “Right-footed” if the preferred foot is Right, and “Unknown” if the preferred foot is NULL.

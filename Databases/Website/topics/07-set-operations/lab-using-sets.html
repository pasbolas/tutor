01 What is this assignment about?

In this assignment, you will practice your knowledge of SET operations to retrieve data from multiple tables using the football database. This assignment represents 3% of your marks.

In this assignment, we are using SET operations to retrieve data, but also ensure the values are clean and organised – so don’t worry if you get an empty table as a result; that means the data is properly inserted!

02 Questions

  • Using SQL SET operators, how would you show which player_id values appear in player_contracts but not in players?
  • Using SQL SET operators, how would you show which clubs are used in player contracts but do not exist in the table clubs?
  • Using a SET operator, list the IDs of players under 20 years old who already have a contract.
  • Using a SET operator, identify players who have an overall rating equal to or greater than 85 but still do not have a contract with any club.
  • Using a SET operator, identify player IDs present in the tables players, player_contracts, and player_attributes. (Hint: you might need to repeat the same set operator).

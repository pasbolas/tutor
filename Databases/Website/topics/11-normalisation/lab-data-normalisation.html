02 Task 1: Identify problems

  • Identify two anomalies that could occur in this design (such as update, insertion, or deletion).
  • Give one concrete example of redundancy in the data.
  • Explain why this structure violates First Normal Form (1NF).

03 Task 2: Transform to first normal form (1NF)

  • Identify which attribute(s) could serve as a primary key.
  • Write SQL code to create a table that satisfies 1NF:
  • every cell contains a single atomic value
  • columns contain values of the same type
  • the table has a defined primary key
  • Insert the sample data provided.

04 Task 3: Transform to second normal form (2NF)

  • In your own words, define partial dependency.
  • Are there any partial dependencies on your 1NF version of the data? If yes, provide examples.
  • Write your own SQL code to divide your 1NF table into smaller tables, removing partial dependencies. Insert the sample data provided into those tables.

05 Task 4: Transform to third normal form (3NF)

  • In your own words, define transitive dependency.
  • Are there any transitive dependencies on your 2NF version of the data? If yes, provide examples.
  • Write your own SQL code to divide your 2NF tables into smaller tables, removing transitive dependencies. Insert the sample data provided into those tables.

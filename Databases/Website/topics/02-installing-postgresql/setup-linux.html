PostgreSQL is a free and open-source relational database management system (DBMS). Tutorials for the available versions of PostgreSQL can be found in this link, and an active community that includes user groups and mailing lists can be found in this link.

03 What is DBeaver?

PostgreSQL databases can be managed using the command line or client software. We will use the second option, so our PostgreSQL database will be connected to DBeaver Community, a free software that allows us to create and manipulate databases using SQL code.

06 How to connect PostgreSQL to DBeaver on a Linux laptop?

PostgreSQL is where your database will be stored. DBeaver is the client side of the database, allowing you to manipulate it through code. For them to work together, they need to be connected. Connect your PostgreSQL database to DBeaver following the steps below:

  1. Open PostgreSQL and click on Start.
  2. Open DBeaver and click on Database -> New Database Connection. Select the PostgreSQL elephant icon and click Next.
  3. In the Connection Settings, configure the following settings:
    • Host: localhost
    • Port: 5432 (default for PostgreSQL)
    • Database: postgres
    • User: postgres
    • Password: the password you created earlier
  1. Click the Test Connection button to ensure that DBeaver can connect to your PostgreSQL database.
  2. If the test is successful, click Finish
  3. In the main DBeaver window, you should see your PostgreSQL connection listed in the Database Navigator on the left. If you cannot see the Database Navigator, click on Window->Database Navigator.

Well done! Now you have installed PostgreSQL, DBeaver, and connected them.

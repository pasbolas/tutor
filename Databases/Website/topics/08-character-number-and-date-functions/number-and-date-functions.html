01 Single-row functions, recap

Single-row functions run once per row and return one result per row. Last lecture covered character functions. This lecture covers the rest of the set:

  • Number functions — accept numeric input, return a numeric value.
  • Date functions — operate on the DATE data type. Every date function returns a DATE, except MONTHS_BETWEEN, which returns a number.
  • Conversion functions — convert a value from one data type to another.
  • General functions — handle NULLs, or pick a return value based on a condition: NVL, NVL2, NULLIF, COALESCE, CASE, DECODE.
Lecturer’s note Number functions accept numeric input and return numeric values. This section covers only some of the available number functions — see “Number Functions” in the Oracle SQL Reference for the full list.Lecturer’s note

06 Number functions

  • ROUND — rounds a value to a specified number of decimal places.
  • TRUNC — truncates (cuts off) a value at a specified number of decimal places, without rounding.
  • MOD — returns the remainder of a division.

Two more useful ones: CEIL rounds up to the nearest integer, and FLOOR rounds down to the nearest integer.

07 Using the ROUND Function

A negative second argument rounds to the left of the decimal point instead of the right. Using -1 rounds to the nearest 10, -2 to the nearest 100, -3 to the nearest 1000, and so on.

ROUND Function ROUND rounds a column, expression, or value to n decimal places. If the second argument is 0 or missing, it rounds to zero decimal places. A second argument of 2 rounds to two decimal places; a second argument of -2 rounds to the nearest 100. ROUND can also be used with dates — you'll see examples later in this lesson.Lecturer’s note

08 Using the TRUNC Function

TRUNC works like ROUND, but it never rounds: it just drops the digits past the cutoff. With a negative second argument, TRUNC zeroes out digits to the left of the decimal point, so 45 becomes 40.

In finance, TRUNC avoids the rounding that could quietly inflate or deflate a balance. It's also handy anywhere a system enforces a strict threshold: if an app operates with fixed resource limits, truncating keeps a count within bounds instead of rounding it up over the limit.

TRUNC Function TRUNC truncates a column, expression, or value to n decimal places, using the same argument rules as ROUND. If the second argument is 0 or missing, it truncates to zero decimal places; -2 truncates two places to the left; -1 truncates one place to the left. Like ROUND, TRUNC can also be used with dates.Lecturer’s note

09 Mod

MOD returns the remainder of a division. It's commonly used to detect even/odd patterns, or to categorise rows based on a numerical pattern.

Suppose a university reviews new research projects, and each project must be assigned to one of 3 review committees. Instead of assigning them by hand, we want a quick rule that spreads the projects evenly. Taking the MOD of the research_id against 3 does exactly that.

10 abs( )

ABS returns the absolute value of a number, turning a negative into a positive. Suppose we want the difference, in days, between a research project's end date and its grant's end date — and we don't want negative values in the result.

SYSDATE Function SYSDATE is a date function that returns the current database server date and time. You use it like any other column name — for example, selecting it from a dummy table called DUAL: SELECT SYSDATE FROM DUAL;Lecturer’s note

14 Conversion Functions

Conversion Functions Columns can be defined using ANSI, DB2, or SQL/DS data types as well as native ones; the server internally converts these to its own data types. When the server encounters data of one type where it expects another, it converts it automatically (implicit conversion) — or you can convert it yourself using a conversion function (explicit conversion). Conversion function names generally follow the pattern datatype_TO_datatype: the first is the input type, the second the output type. Implicit conversion exists, but explicit conversion is recommended, since it keeps your SQL statements reliable and predictable.Lecturer’s note

15 Cast( )

CAST(attribute AS data_type) converts a value to another data type for processing. The double-colon syntax (::) is shorthand for the same thing.

16 Using the TO_CHAR Function with Dates

Two format options worth knowing for TO_CHAR with dates:

  • fm (fill mode) strips the leading spaces or padding that some format elements add by default.
  • th formats a number as a spelt-out ordinal, with the correct suffix ("st", "nd", "rd", "th").

17 Date Format of to_char

Suffixes you can add to a date format, for the day number:

  • TH — ordinal suffix only, e.g. DDTH → 4TH
  • SP — spelled out, e.g. DDSP → FOUR
  • SPTH — spelled out plus ordinal, e.g. DDSPTH → FOURTH

19 Create your own function (PL/pgSQL)

PL/pgSQL (Procedural Language/PostgreSQL) lets you write reusable, named blocks of code for logic that's too complex for a single query. It extends plain SQL with control structures like loops and conditionals, and functions written in it are often used as triggers, running automatically in response to an INSERT, UPDATE, or DELETE on a table.

HCI Question 4 Study Notes

From CMPU2008 Human Computer Interaction revision material.

Contents

This page covers only the expected Question 4 topics: affordance, mental models, Gestalt Laws, and Nielsen's 10 usability heuristics.

Q4(a) Affordance

Main idea: affordance suggests how an object or interface element can be used.

Definition: An affordance is a property of an object or interface element that suggests how it can be used. In HCI, affordances help users understand possible actions without needing detailed instructions.
Example Affordance User expectation
ButtonLooks pressable or clickable.User expects it to perform an action.
ScrollbarShows content can be moved up or down.User expects to scroll.
Text fieldEmpty box suggests typing is possible.User expects to enter text.
SliderMovable handle suggests adjustment.User expects to drag it to change a value.
Trash iconSuggests deleting or removing something.User expects it to remove an item.

Good and poor affordance

Type Explanation Example
Good affordanceThe user can easily understand what action is possible.A raised button labelled Submit.
Poor affordanceThe user cannot tell what is clickable, draggable, or usable.Plain text used as a button with no visual clue.
Exam answer
An affordance is a feature of an object or interface that suggests how it should be used. For example, a button affords clicking, a scrollbar affords scrolling, and a text box affords typing. Good affordances make interfaces easier to understand because users can see what actions are possible.

Q4(b) Mental models

Main idea: users carry expectations about how systems work.

Definition: A mental model is a user's internal understanding or expectation of how a system works. Users rely on mental models to predict what will happen when they interact with an interface.
Example Mental model Design implication
Shopping cart iconItems can be added before checkout.Use familiar cart behaviour in online shops.
Floppy disk iconClicking saves the file.Use familiar save symbols or clear labels.
Back buttonReturns to the previous screen.Back navigation should behave consistently.
Magnifying glassSearch function.Use common icons for common actions.

Why mental models matter

  • They help users predict system behaviour.
  • They reduce learning effort.
  • They make interfaces feel familiar.
  • They help designers avoid confusing users.
  • They are useful during testing because mismatches reveal design problems.

Erroneous mental model examples

Erroneous mental model Problem Design response
User thinks deleting an app also deletes the account.User may think their personal data is gone when it is not.Show clear account deletion information.
User thinks closing a browser tab logs them out.Security risk on shared devices.Use clear logout messages and session warnings.
User thinks pressing Back cancels a payment.User may accidentally leave a process or duplicate actions.Show confirmation and transaction status clearly.
User thinks saving is automatic when it is manual.Work may be lost.Use autosave indicators or visible save controls.
Exam answer
A mental model is a user's understanding of how a system works. Mental models are important because users rely on them to predict what actions will do. For example, users expect a shopping cart icon to store items before checkout and a back button to return to the previous page. If the interface does not match the user's mental model, errors and confusion can occur.

Q4(c) Gestalt Laws with examples

Main idea: Gestalt Laws explain how people visually group and organise information.

Definition: Gestalt Laws are principles of visual perception that describe how users naturally organise visual elements into patterns, groups, and meaningful structures.
Gestalt Law Meaning Screen design example
Proximity Items close together are seen as related. Place a label close to its form field so users know they belong together.
Similarity Items that look similar are seen as part of the same group. Use the same style for all primary buttons.
Continuity Users prefer smooth, continuous paths or flows. Arrange steps in a checkout process from left to right or top to bottom.
Closure Users mentally complete incomplete shapes or patterns. Use simple icons where users can recognise the meaning even with minimal detail.
Figure-ground Users separate the main object from the background. Use contrast so a popup, button, or warning message stands out from the page.

How Gestalt Laws help interface design

  • They improve visual organisation.
  • They make screens easier to scan.
  • They help group related information.
  • They guide user attention to important content.
  • They reduce confusion in complex layouts.
Exam answer
Gestalt Laws explain how users organise visual information. Proximity means items close together are seen as related. Similarity means items that look alike are grouped together. Continuity means users follow smooth visual paths. Closure means users complete incomplete shapes mentally. Figure-ground means users separate the main object from the background. These laws help designers create clearer layouts and better visual grouping.

Q4(d) Nielsen's 10 heuristics with examples

Main idea: Nielsen's heuristics are usability principles used to evaluate interface design.

Definition: Nielsen's 10 heuristics are general usability guidelines used to identify problems in user interface design.
Heuristic Meaning Example
1. Visibility of system status Keep users informed about what is happening. Show a loading spinner, progress bar, or confirmation message.
2. Match between system and real world Use familiar words, concepts, and order. Use “basket” or “cart” in an online shop instead of technical database terms.
3. User control and freedom Allow users to undo, cancel, or leave unwanted actions. Provide Undo, Cancel, Back, or Exit options.
4. Consistency and standards Use the same patterns and meanings across the interface. Use the same button style for the same type of action.
5. Error prevention Prevent problems before they happen. Disable Submit until required fields are completed.
6. Recognition rather than recall Make options visible so users do not need to remember information. Show menu options, recent searches, or visible form hints.
7. Flexibility and efficiency of use Support both beginners and experienced users. Provide keyboard shortcuts or saved templates for expert users.
8. Aesthetic and minimalist design Remove unnecessary information and clutter. Use a clean checkout page with only essential fields.
9. Help users recognise, diagnose, and recover from errors Error messages should explain the problem and solution. Show “Password must contain 8 characters” instead of “Invalid input”.
10. Help and documentation Provide support when users need guidance. Include FAQs, tooltips, onboarding screens, or searchable help pages.

Using heuristics in an evaluation

  1. Select Nielsen's 10 heuristics as the evaluation criteria.
  2. Inspect the interface screen by screen.
  3. Record usability problems linked to specific heuristics.
  4. Rate the severity of each problem.
  5. Suggest design improvements.
Exam answer
Nielsen's heuristics are usability principles used to evaluate interfaces. Examples include visibility of system status, such as showing a progress bar; consistency and standards, such as using the same button style throughout; error prevention, such as disabling submit until required fields are complete; and help users recover from errors, such as giving clear error messages that explain how to fix the problem.

HCI Question 2 Study Notes

From CMPU2008 Human Computer Interaction revision material.

This page covers only the expected Question 2 topics: accessibility and usability for aging users, personas, personas in design, and empathy maps.

Q2(a). Accessibility and usability for aging users

Main idea: aging can affect vision, hearing, movement, memory, and confidence when using digital interfaces.

Definition: Accessibility means designing interfaces so older users can access and use them despite age-related changes. Usability means making the interface easy, efficient, and comfortable for them to use.
Age-related factor Effect on interface use Design response
Reduced vision Small text, low contrast, and crowded layouts become harder to read. Use larger text, strong contrast, clear spacing, and readable fonts.
Reduced hearing Audio alerts, spoken instructions, or notification sounds may be missed. Use captions, visual alerts, vibration, and text alternatives.
Reduced motor control Small buttons, precise gestures, and fast interactions become difficult. Use large buttons, simple gestures, generous spacing, and slower timeouts.
Memory and cognitive changes Complex menus, hidden actions, and long processes may confuse users. Use simple navigation, clear labels, step-by-step guidance, and consistent layouts.
Exam answer
Two age-related factors that affect accessibility and usability are reduced vision and reduced motor control. Reduced vision can make small text or low contrast difficult to read, so interfaces should use larger text and strong contrast. Reduced motor control can make small buttons and precise gestures difficult, so interfaces should use larger clickable areas and simple interaction methods.

Q2(b).Personas

Main idea: a persona is a realistic user profile based on user research.

Definition: A persona is a fictional but realistic representation of a target user group. It is based on research and describes the user’s goals, needs, behaviours, and challenges.

Information included in a persona

Information Purpose
Name and basic profileMakes the user type easier to remember.
Age and backgroundShows relevant context about the user.
GoalsShows what the user wants to achieve.
TasksShows what the user needs to do with the system.
NeedsShows what the design must support.
Frustrations or pain pointsShows problems the design should avoid or solve.
Technology experienceShows whether the user is novice, average, or expert.
Accessibility needsShows barriers related to vision, hearing, motor control, or cognition.
Exam answer
A persona is a fictional but realistic profile of a target user based on user research. A persona may include a name, age, background, goals, tasks, needs, frustrations, technology experience, and accessibility needs.

Q2(c). Personas in design

Main idea: personas help designers focus on real user needs instead of designing for themselves.

How personas are used in design

Use Explanation
Guide design decisionsDesigners can ask whether a feature helps the persona achieve their goals.
Keep focus on usersPersonas prevent the team from designing only for their own preferences.
Support communicationThey give the design team a shared understanding of target users.
Identify requirementsPersonas help identify what the system must do for different user groups.
Support testing scenariosPersonas help create realistic tasks for usability testing.

Pros and cons of personas

Pros Cons
Help designers understand target users. Can become inaccurate if not based on real research.
Make user needs easier to remember. Can oversimplify users and ignore individual differences.
Support better design decisions. Can become stereotypes if poorly created.
Improve team communication. Can become outdated if user needs change.
Help create realistic user scenarios. May be ignored if the team does not use them properly.
Exam answer
Personas help design teams understand target users and make user-focused decisions. They can guide features, requirements, and usability testing scenarios. Their advantages include clearer user focus, better communication, and more realistic design decisions. Their disadvantages are that they can become inaccurate, outdated, oversimplified, or stereotyped if they are not based on real research.

Q2(d). Empathy map

Main idea: an empathy map organises user research into four areas to understand the user better.

Definition: An empathy map is a user research tool that helps designers organise what users say, think, do, and feel. It helps translate research findings into design ideas.

Says

What the user directly says in interviews, testing, or feedback.

Example: “I cannot find the submit button.”

Thinks

What the user may be thinking but may not say directly.

Example: “This process feels confusing.”

Does

What the user physically does while using the system.

Example: Repeatedly goes back to the previous page.

Feels

The user’s emotions during the interaction.

Example: Frustrated, uncertain, confident, rushed.

How empathy maps help design

Research finding Possible design idea
User says they cannot find a feature.Improve labels, navigation, and visual hierarchy.
User thinks the process is too complex.Reduce steps and simplify the flow.
User repeatedly makes the same mistake.Add clearer instructions, feedback, or error prevention.
User feels anxious or unsure.Use confirmation messages, progress indicators, and reassuring wording.
Exam answer
An empathy map has four quadrants: says, thinks, does, and feels. It helps designers organise user research by showing what users say, what they think, what actions they take, and how they feel. This can be used to translate research into design ideas, such as clearer navigation, simpler steps, better feedback, and improved error prevention.
